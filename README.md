# 🦉 Игривый совёнок

Полноценный сайт с PWA-приложением для установки на телефон.

## 📂 Файлы проекта
- `index.html` — главный сайт
- `login.html` — вход и регистрация покупателей
- `admin-login.html` — вход администратора
- `manifest.json` — PWA-манифест
- `sw.js` — Service Worker (офлайн-режим)
- `README.md` — эта инструкция

## 🚀 Как запустить

### Локально (на компьютере)
1. Создайте папку `owl-site`
2. Скопируйте в неё все 6 файлов
3. Откройте `index.html` в браузере

### На хостинге (для PWA и ссылок)
PWA работает только через **HTTPS** или **localhost**. Варианты:

**Вариант 1: GitHub Pages (бесплатно)**
1. Создайте репозиторий на GitHub
2. Загрузите все файлы
3. Settings → Pages → Source: main branch
4. Получите ссылку вида `https://username.github.io/owl-site/`

**Вариант 2: Netlify (бесплатно)**
1. Зайдите на netlify.com
2. Перетащите папку с файлами
3. Получите HTTPS-ссылку
